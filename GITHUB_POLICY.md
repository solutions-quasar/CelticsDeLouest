# GITHUB REPOSITORY POLICY

**IMPORTANT NOTICE**

This GitHub repository is exclusively for the **TEST / STAGING** version of the Celtics de l'Ouest application.

1.  **NO PRODUCTION CODE**: Do not push production configurations, keys, or specific production-only logic to this repository.
2.  **NO PRODUCTION DEPLOYMENT**: This repository configures deployment to the `staging` environment (Test App) only.
3.  **FIREBASE ONLY**: The Production application lives exclusively on Firebase. Updates to production should be managed directly via Firebase CLI from a secure local environment, or by carefully merging vetted changes from this Test branch locally.

**Current Branch: `test`**
This branch tracks the development of the Test App.
