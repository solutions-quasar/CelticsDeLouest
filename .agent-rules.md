# IMPORTANT PROJECT RULES

## Localhost
- **Port**: `3000` → `npx serve -p 3000 .` from the project root
- Other active ports on this machine: `3002` (Premium-Quasar), `5000` (ERP backend)

1.  **NEVER AUTO-PUSH**: Do not push any code to GitHub (or deploy anywhere) without explicit authorization from the user for each specific push.
    *   Wait for the user to say "push", "deploy", or "update github".
2.  **GITHUB IS TEST ONLY**: The GitHub repository is strictly for the **Test / Staging** application.
    *   Do not put Production keys or configs here.
    *   Do not deploy to Production from here.
